Python & REST API Integration

Python Usage (3 lines)

import requests

res = requests.post("http://localhost:7860/api/tts/generate", json={
    "text": "Hello world from Python!",
    "voice": "en-US-JennyNeural",
    "engine": "edge-neural"
})
with open("speech.mp3", "wb") as f:
    f.write(requests.get(f"http://localhost:7860{res.json()['audioUrl']}").content)

Voice Cloning Endpoint (cURL)

curl -X POST http://localhost:7860/api/tts/clone \
  -F "referenceAudio=@sample.wav" \
  -F "text=Hello, this is cloned speech"
